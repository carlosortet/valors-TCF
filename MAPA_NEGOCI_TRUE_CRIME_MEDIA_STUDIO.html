  • YouTube AdSense - CPMs preferencials via MCN (8-15 EUR/1000 views)
  • Spotify Ads - Monetitzacio de podcast via Spotify Audience Network
  • Branded Content / Patrocinis - Integracions a podcasts, YouTube, newsletter
  • Content-ID - Reclamacio de drets, ingressos passius per duplicats

Es genera un cercle virtuos: el nucli alimenta les plataformes, genera ingressos diversificats, permet crear producte premium i experiencies, que alimenten prestigi, comunitat i noves dades que tornen a reforcar el nucli.

El Cercle Virtuos en Detall:

  1. El nucli de Casos de True Crime genera contingut de qualitat
  2. Alimenta totes les plataformes (YouTube, Spotify, Web, TikTok)
  3. Genera ingressos diversificats (publicitat, subscripcions, patrocinis)
  4. Permet crear producte premium i experiencies (drops, esdeveniments)
  5. Aquestes alimenten prestigi, comunitat i noves dades
  6. Torna a reforcar el nucli amb mes recursos i autoritat
Es el sistema que utilitzen marques multimedia d'alt rendiment com Vox Media, The Athletic, i Morning Brew.

Resultat Final

Un model totalment integrat i escalable. S'ha passat de tenir continguts dispersos a tenir una estructura completa de negoci multicanal, basada en contingut, comunitat, experiencies i IP.
